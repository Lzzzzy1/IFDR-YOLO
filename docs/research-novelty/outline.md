# Evidence-Mapped Outline

## 1. 结论与研究边界

- Sources: [1][7][8][9][10][11][17][18]
- Claims: 原 P2+BiFPN+WIoU 只具工程价值；绝对“无人研究”不可证明；给出截至 2026-07-28 的有界检索结论。
- Counter-claim: 同构方法可能存在于未检索数据库、非英文论文、专利或未公开代码中。
- Recency: 2025-2026 预印本需要降级置信度。

## 2. 为什么模块叠加不能成为博士课题

- Sources: [7][8][9][10][11][12][17][18]
- Claims: 逐像素融合、条件 FPN、稀疏高分辨率、可靠性路由、共享质量分配和尺度损失均已有先例。
- Counter-claim: 面向 KITTI 的新组合仍可能有应用价值，但不能自动构成方法学创新。

## 3. 科学问题：分辨率—可见性退化下的可靠检测

- Sources: [10][14][15][16][19]
- Claims: 区分采样/混叠、遮挡、标注边界不确定和预测不确定；静态 attention 无法保证语义可识别性。
- Counter-claim: 可控退化可能不能代表真实相机退化。

## 4. 首选博士研究计划：反事实退化校准检测

- Sources: [9][10][13][14][15][16][17][18]
- Claims: 用干预对监督因子化退化后验；后验统一但非标量地控制路由、分配和概率回归；加入计算约束。
- Counter-claim: 可被描述为 LER-YOLO+TOOD+QueryDet+不确定性回归的组合。
- Falsification: 后验不可校准、共享控制无非冗余收益、等算力优势消失、跨域失效。

## 5. 备选研究计划

- Program B sources: [10][12][13][14][18]
- Program C sources: [1][9][19][20]
- Claims: B 为尺度条件梯度预算理论；C 为风险校准条件感知。
- Counter-claim: B 与 UGS 重叠强；C 可能偏离检测并导致幻觉。

## 6. 两到三周可完成的第一阶段

- Sources: [1][2][9][10][19]
- Claims: 修复数据和官方评价；建立受控退化诊断集；实现单因子可靠性预测；只耦合一个路由与一个优化点；做严格对照。
- Counter-claim: 短期结果只能支持可行性，不能支持博士级完整结论。

## 7. 一到三年成果链

- Sources: [9][10][14][15][16][18][19][20]
- Claims: 诊断/基准、表示/路由、优化/不确定性、跨域/安全效率四条论文线。
- Counter-claim: 成果线过宽，需要根据第一阶段否证结果收缩。

## 8. 实验、统计和复现协议

- Sources: [1][2][4][5][7][9][10][19]
- Claims: KITTI AP40、DontCare、固定划分、多种子、等参数/等 FLOP、校准、延迟、跨数据集、失败分析。
- Counter-claim: KITTI 极小目标被官方协议排除，需要额外非官方指标并明确标注。

## 9. 新颖性与文本查重治理

- Sources: [2][3][4][5][6]
- Claims: 保留检索日志、功能权利要求矩阵、代码许可证与引用；区分文本相似度和科学新颖性；不使用“全球首次”。
- Counter-claim: 公开检索和软件查重都无法覆盖未公开研究。

## 10. 局限、风险和决策门

- Sources: [6][10][17][20]
- Claims: 预印本变化、专利覆盖、负迁移、仿真到真实差距、资源约束。
- Counter-claim: 最稳妥成果可能是严谨的负结果或诊断基准，而非新检测器。
