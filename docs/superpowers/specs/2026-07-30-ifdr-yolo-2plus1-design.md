# IFDR-YOLO 2+1 闭环研究设计

> 状态：研究方向与总体设计已获用户确认  
> 日期：2026-07-30  
> 第一阶段目标：形成可复现、可证伪、可用于会议投稿的道路小目标检测方法  
> 长期目标：扩展为硕士学位论文主体，并保留博士课题的后续研究接口

## 1. 研究定位

### 1.1 核心问题

道路场景中的远距离行人、骑行者和车辆会受到有效采样率不足、混叠、模糊与遮挡影响。P2 检测层能够保留高分辨率细节，但也会放大道路纹理、车道线和背景噪声；固定 PAN-FPN 或全局加权 BiFPN 无法判断当前局部位置的浅层特征是否可靠；普通 IoU 损失也把清晰目标和边界模糊目标当作具有相同定位确定性的样本。

本项目研究：

> 能否通过可控单因素干预学习可辨识的道路小目标退化状态，并使用同一退化状态同时控制 P2-P5 局部特征融合和不确定性边界框定位？

### 1.2 研究边界

第一阶段只研究 RGB 二维目标检测，不引入 LiDAR、红外、深度估计、跟踪或语义分割模型。P2、BiFPN/ASFF、WIoU、Inner-IoU 和普通注意力均作为对照或工程基础，不单独声明原创。

第一阶段必须完成：

1. KITTI 与 CityPersons 两个道路场景数据集；
2. 两个可观测退化因素；
3. 一个由退化因素与预测分布派生的定位不确定性；
4. 退化条件的双向特征融合；
5. 退化条件的边界框定位目标；
6. 完整消融、等参数对照、分组评测和失败分析。

以下内容仅作为后续博士课题扩展，不进入第一阶段核心实现：

1. 退化条件的正样本分配；
2. 稀疏 P2 条件执行；
3. 第三数据集和第二类检测器迁移；
4. 视频时序可靠性；
5. 多模态可靠性。

## 2. 核心假设与否证条件

### H1：退化因素可辨识

在单因素干预下，模型能够识别有效采样/混叠状态 \(z_s\) 与可见性状态 \(z_v\)，且未被干预因素的输出保持相对稳定。

否证条件：退化预测不优于图像尺寸、局部方差或模糊度等简单统计基线，或者单因素干预同时无差别改变所有因素输出。

### H2：退化因素能解释尺度可靠性

清晰小目标、混叠小目标和遮挡小目标需要不同的 P2-P5 局部融合权重。受监督的因子化退化状态应优于固定融合、全局可学习权重和无监督注意力。

否证条件：等参数、等 FLOPs 对照后增益消失，或融合权重与干预强度、目标尺度和可见性没有稳定关系。

### H3：定位不确定性能够稳定回归

由 \(z_s\)、\(z_v\) 与 DFL 分布熵派生的定位不确定性 \(u_b\) 能够校准定位残差，并在极小、混叠和遮挡目标上改善定位，同时不通过无限降低困难样本权重逃避学习。

否证条件：不确定性与定位残差不相关、校准劣于简单面积启发式，或整体定位性能因困难样本被过度抑制而下降。

### H4：共享退化状态具有非冗余价值

同一退化状态同时控制融合与定位应优于两个相互独立、参数量匹配的控制器。

否证条件：独立控制器稳定优于共享控制器。若发生该情况，论文必须收缩为“退化监督的尺度可靠性融合”，不得继续声称统一机制。

## 3. 2+1 退化表示

### 3.1 有效采样与混叠状态 \(z_s\)

\(z_s \in [0,1]\) 表示局部区域因下采样、重采样和亚像素相位导致的有效细节损失。0 表示接近清晰原始观测，1 表示严重采样不足或混叠。

监督来源：

1. 已知比例的缩小-放大；
2. 相同缩放比例下抗混叠开/关配对；
3. 亚像素平移后重采样；
4. 有限强度的模糊与压缩，仅作为混叠伴随条件；
5. 清晰恒等样本。

### 3.2 可见性状态 \(z_v\)

\(z_v \in [0,1]\) 表示局部目标不可见程度。0 表示完整可见，1 表示严重遮挡。

监督来源：

1. KITTI 原始遮挡等级；
2. CityPersons 可见框与全身框的面积或高度比例；
3. 使用软边缘、结构化遮挡块生成的已知可见比例；
4. 与目标区域匹配的背景遮挡负样本。

### 3.3 派生定位不确定性 \(u_b\)

不把随机标注扰动当作可从 RGB 直接识别的独立因素。定位不确定性由可观测退化与预测分布共同决定：

\[
u_b =
\operatorname{clip}
\left(
\alpha_s z_s+\alpha_v z_v+\alpha_h H_{\mathrm{DFL}},
0,1
\right)
\]

其中 \(\alpha_s,\alpha_v,\alpha_h\) 为非负且归一化的可学习系数，\(H_{\mathrm{DFL}}\) 为归一化 DFL 边界分布熵。系数、熵定义和裁剪边界必须进入配置与实验记录。

\(u_b\) 通过定位残差校准损失接受监督，但进入主定位损失的路径在第一版中停止梯度，防止模型主动放大不确定性以降低检测损失。

## 4. 受控干预数据协议

### 4.1 清单驱动的在线干预

不复制或覆盖原始数据。为每个训练样本生成确定性的干预清单，至少记录：

- 数据集、图像 ID 和对象 ID；
- 干预类型与强度；
- 随机种子；
- 作用区域和软掩码参数；
- 几何变换参数；
- \(z_s\)、\(z_v\) 监督目标；
- 是否为目标区域或匹配背景区域；
- 实现版本和配置哈希。

图像变换在 Dataset 中在线执行，清单和随机种子保证同一实验可重现。

退化监督图必须同时携带监督有效掩码。已知干预区域、具有真实可见性标注的对象区域和恒等对照区域进入因素损失；没有退化标注的自然背景不被默认标记为“清晰可见”，避免把未知区域错误地当作负样本。

### 4.2 防止目标位置泄漏

只在真实框内部施加退化会泄漏目标位置，因此必须同时执行：

1. 随机目标区域干预；
2. 面积、纵向位置和背景纹理匹配的非目标区域干预；
3. 全局干预；
4. 无干预恒等样本；
5. 软边缘混合，禁止明显矩形边界；
6. 干预类别与目标类别独立采样。

退化头必须在“只有背景被干预”的样本上保持低目标置信度，避免把人工痕迹当作目标提示。

### 4.3 几何一致性

会改变空间几何的干预必须同步更新图像、检测框、可见框和退化监督图。仅改变图像质量的干预不得修改干净检测框。

所有目标框在变换后必须满足有限值、正面积和图像边界约束。被裁剪至无有效可见区域的目标按显式规则忽略，不得静默保留非法框。

## 5. 模型架构

### 5.1 检测基础

使用已经验证的 YOLOv8m-P2 模型：

- Backbone 输出 P2-P5；
- PAN 路径包含自顶向下和自底向上融合；
- Detect 使用 stride 4、8、16、32 四个检测尺度；
- 继续使用已验证的语义前缀预训练初始化。

### 5.2 因子化退化估计器

每个双向融合节点接收两个已对齐到同一空间尺寸的分支。每个分支先通过节点专属的 \(1\times1\) 投影映射到默认 32 个可靠性通道，再将投影特征拼接，通过共享的深度可分离 \(3\times3\) 核心提取局部退化表示。

两个独立的 \(1\times1\) 输出头分别产生 \(z_s\) 和 \(z_v\) 的空间图。节点专属投影解决 P2-P5 通道数不同的问题，共享核心用于约束不同尺度具有一致的退化语义。

可靠性通道数、共享方式和输出温度均为显式配置。默认可靠性通道数为 32。

### 5.3 ReliabilityGatedConcat

不直接修改 Ultralytics 模型解析器。先构建标准 P2 模型，再把指定 PAN `Concat` 节点替换为输出通道数不变的 `ReliabilityGatedConcat`。

对于第 \(i\) 个输入分支：

\[
\hat F_i =
\left[
1+\gamma(t)\left(w_i-\frac{1}{N}\right)
\right]F_i
\]

\[
w_i = \operatorname{Softmax}_i(a_i(F_i,z_s,z_v))
\]

其中 \(N=2\)，门控强度由训练日程与可学习参数共同决定：

\[
\gamma(t)=r(t)\operatorname{sigmoid}(\gamma_0)
\]

\(r(t)\) 在 epoch 1-5 严格为 0，在 epoch 6-15 从 0 线性增加到 1，之后保持 1。模型构建和前五个 epoch 因此与原始拼接严格等价，同时 \(\gamma_0\) 在门控开放后仍可学习。

门控后沿通道维拼接，输出通道数与原始 `Concat` 完全一致，因此后续 C2f 和 Detect 无需修改。

必须记录每个节点的：

- 分支权重分布；
- P2 使用比例；
- \(z_s,z_v\) 热图；
- 门控强度；
- 干预强度条件下的权重变化。

### 5.4 辅助输出传递

`ReliabilityGatedConcat` 的本轮辅助张量只保存在模块的短生命周期上下文中。`IFDRDetectionModel` 在损失计算时通过 `consume_reliability_context()` 一次性读取并清空上下文。

约束：

1. 上下文不进入 `state_dict`；
2. 每次前向只能消费一次；
3. 验证和推理不得遗留训练图；
4. DDP 每个进程只访问自身模型副本；
5. checkpoint 恢复不依赖上下文状态。

### 5.5 从可靠性图到正样本

每个 Detect 输入尺度保留一张与其空间尺寸一致的 \(z_s,z_v\) 图。Task-Aligned Assigner 完成正样本匹配后，按每个正样本所属检测尺度和 anchor point 位置双线性采样对应可靠性值。

DFL 熵与可靠性值均以正样本为单位计算。若某个检测尺度没有正样本，该尺度不产生定位校准项，但仍可产生像素级因素监督。禁止用验证标签或最终预测框反向构造训练可靠性目标。

## 6. 定位目标

保留 Task-Aligned Assigner 和原始 DFL，第一阶段只替换主 IoU 回归项。

设基础定位误差为：

\[
e_b = 1-\operatorname{CIoU}(\hat b,b)
\]

将停止梯度后的 \(u_b\) 映射到有界尺度：

\[
\sigma_b = 1 + \beta\operatorname{stopgrad}(u_b),
\quad 0 \le \beta \le 1
\]

定义退化条件定位损失：

\[
L_{\mathrm{DCLI}} =
\frac{e_b}{\sigma_b}+\log \sigma_b
\]

该形式限制最大降权幅度，并通过 \(\log\sigma_b\) 抑制无界不确定性。默认 \(\beta=0.5\)，必须与 0、0.25、0.5、1.0 做灵敏度分析。

定位不确定性校准项：

\[
L_{\mathrm{cal}} =
\operatorname{SmoothL1}
\left(
u_b,
\operatorname{stopgrad}(\tilde e_b)
\right)
\]

其中 \(\tilde e_b\) 为按目标尺度归一化并裁剪到 \([0,1]\) 的定位残差。归一化统计只从训练集估计并保存，不得使用验证集。

WIoU、Inner-IoU 和原始 CIoU 作为独立对照。不得把 DCLI 的通用异方差形式单独声明为原创；论文贡献是可辨识退化状态与定位的受控耦合。

## 7. 总训练目标与日程

\[
L =
L_{\mathrm{det}}
+\lambda_s L_s
+\lambda_v L_v
+\lambda_{\mathrm{sel}}L_{\mathrm{selectivity}}
+\lambda_{\mathrm{cal}}L_{\mathrm{cal}}
+\lambda_{\mathrm{cons}}L_{\mathrm{pair}}
\]

所有系数必须进入配置并写入 `config.resolved.yaml`。

默认 300 epoch 日程：

1. epoch 1-5：门控强度保持 0，DCLI 关闭，只训练基础检测与退化估计；
2. epoch 6-15：门控强度和 DCLI 系数线性增加；
3. epoch 16-300：完整联合训练；
4. 前 15 epoch 中，退化状态进入定位路径时始终停止梯度；
5. 第一阶段正式实验全程保留停止梯度；取消停止梯度仅作为消融。

若退化头在 epoch 5 结束时不能在固定的训练集诊断视图上优于简单统计基线，不进入完整联合训练。诊断视图使用训练图像但采用未参与在线采样的固定干预参数组合，只作为机制健康检查，不用于报告最终检测性能或选择最终 checkpoint。

### 8.1 IFDRDetectionModel

继承固定版本 Ultralytics `DetectionModel`：

1. 使用标准 P2 YAML 构建基础图；
2. 按配置中的节点索引替换融合节点；
3. 覆盖 `init_criterion()` 返回项目内 `IFDRDetectionLoss`；
4. 提供辅助上下文的消费接口；
5. 提供结构检查和方法清单导出。

### 8.2 IFDRTrainer

继承 `DetectionTrainer`：

1. `get_model()` 返回 `IFDRDetectionModel`；
2. `build_dataset()` 返回携带退化监督的 Dataset；
3. 保持 Ultralytics 验证器和标准检测输出兼容；
4. 扩展 loss 名称和训练日志；
5. 不使用运行时全局猴子补丁。

### 8.3 IFDRRuntimeAdapter

实现现有 `RuntimeAdapter` 协议：

1. 模型构建与预训练迁移；
2. 自定义 Trainer 注入；
3. 自定义 checkpoint 加载；
4. 预测前显式导入项目模型类；
5. 方法配置、源文件哈希和结构摘要写入运行目录。

### 8.4 Checkpoint

正式 checkpoint 必须包含：

- 模型权重；
- 优化器与学习率调度状态；
- epoch；
- 退化模块配置；
- 因子归一化统计；
- Ultralytics 版本；
- Git commit；
- 数据与干预清单哈希。

同时保存纯 `state_dict` 版本，避免 Python pickle 类路径变化导致无法恢复。

## 9. 数据集与评价

### 9.1 KITTI

沿用已验证的 Chen train/val 划分、真实图像尺寸标签转换和 KITTI AP40。

预注册主要指标：

1. Pedestrian Moderate/Hard AP40；
2. Cyclist Moderate/Hard AP40；
3. 三类 mean Moderate AP40；
4. 按原始框高、遮挡和截断分组的 AP/Recall；
5. mAP50 与 mAP50-95 作为辅助指标。

### 9.2 CityPersons

使用官方 train/validation 划分和 ignore regions。模型为单类 Pedestrian，不把 CityPersons 强行映射为 KITTI 三类。

主要指标：

1. 官方 log-average miss rate \(MR^{-2}\)；
2. Reasonable；
3. Small；
4. Heavy Occlusion；
5. 按可见比例分组的误检率；
6. CityPersons 训练到 KITTI Pedestrian 的迁移结果。

数据准备必须保存官方文件哈希、许可说明、划分清单和转换审计。

## 11. 测试与验收

### 11.1 数据测试

- 同一清单和种子生成完全相同的干预；
- 零强度干预与原图在规定误差内一致；
- 图像、框、可见框和监督图几何一致；
- 目标干预与背景负干预数量和尺度分布可审计；
- 不产生非法框、NaN 或 Inf；
- 原始数据只读。

### 11.2 模型测试

- 替换融合节点后输出形状和通道与原模型一致；
- 初始化门控严格等价于原始拼接；
- 融合权重非负且沿分支求和为 1；
- 单因素干预选择性损失方向正确；
- 辅助上下文只能消费一次且不会跨 batch 泄漏；
- 所有新增参数获得有限梯度；
- 极小框、无交集框和 AMP 下损失有限；
- checkpoint 与纯 `state_dict` 往返恢复一致；
- 单 batch、单 epoch smoke 训练和预测通过。

### 11.3 评价测试

- KITTI AP40 继续通过参考实现检查；
- CityPersons ignore region 和 \(MR^{-2}\) 与官方或可信参考小样本一致；
- 空预测、空真值、完全匹配和重复预测边界情况可验证；
- 分组指标的对象集合可追溯到原始标注。

## 12. 反塌缩与失败处理

必须监控：

- \(z_s,z_v\) 均值、方差和直方图；
- 每个因素与干预强度的相关性；
- 未干预因素的一致性；
- 各融合节点权重熵；
- \(u_b\) 与定位残差的校准曲线；
- P2 使用比例；
- clean 与 degraded 性能差；
- 梯度范数。

触发以下任一条件时停止扩大模型：

1. 因素输出方差接近 0；
2. 只识别人工边界而不识别退化强度；
3. 参数匹配后融合增益消失；
4. 共享控制不优于独立控制；
5. 只在合成退化集上提升；
6. CityPersons 无法保持方向一致；
7. 三随机种子结论不稳定；
8. 小目标提升伴随不可接受的总体性能下降。

## 13. 论文贡献边界

论文最多声明三项贡献：

1. 面向道路小目标的单因素受控退化协议和选择性诊断；
2. 使用可辨识因子化退化状态的 P2-P5 局部双向融合；
3. 同一退化状态与不确定性定位的联合机制及非冗余消融。

论文不得声明：

- P2、BiFPN、WIoU 或异方差损失本身为原创；
- 所有可靠性融合均为首次；
- “全球首次”“完全原创”或“从未有人研究”；
- 单数据集、单随机种子或未匹配计算量的提升能够证明核心机制。

投稿前必须更新英文、中文、预印本、代码和专利检索。可使用的有限表述为：

> 截至检索日期，在已记录的公开来源和功能同义检索范围内，尚未识别到使用受控单因素干预学习道路小目标因子化退化状态，并验证同一状态同时控制跨尺度融合与不确定性定位的等价方法。
