# IFDR-YOLO 研究设计规范

> 状态：老师与项目负责人已批准研究方向  
> 日期：2026-07-28  
> 目标：以 KITTI 道路小目标检测为起点，形成可复现、可否证、可投稿的会议论文  
> 本文取代：`2026-07-28-yolov8m-p2-bifpn-wiou-design.md` 作为主研究方案；旧方案保留为工程基线

## 1. 项目题目

中文暂定题目：

> 基于干预监督与因子化退化可靠性学习的道路小目标检测

英文暂定题目：

> IFDR-YOLO: Intervention-Supervised Factorized Degradation Reliability Learning for Small Road-User Detection

题目在论文完成前可以调整，但“干预监督、因子化退化、可靠性路由”三项含义不得在没有新设计评审的情况下改变。

## 2. 研究背景与问题

YOLOv8 默认使用 P3、P4、P5 三个检测尺度。KITTI 中远距离行人和骑行者像素尺寸较小，经过连续下采样后，轮廓和位置细节容易丢失。增加 P2 能保留高分辨率浅层特征，但也会同时保留车道线、纹理、混叠和传感器噪声。

已有研究已经大量采用 P2、BiFPN、WIoU、Inner-IoU 等模块。直接组合这些模块不能构成本文的主要新颖性。本项目研究的核心问题是：

> 在分辨率不足、混叠噪声、遮挡和边界不确定性条件下，不同尺度特征的可靠程度并不相同。能否通过可控干预学习具有明确语义的因子化退化后验，并使用同一后验协调高分辨率尺度路由和不确定性定位？

## 3. 核心假设

### H1：退化因素可识别

已知的单因素干预能够使模型区分分辨率、混叠、可见性和边界不确定性，而不是只学习类别、背景或图像位置捷径。

### H2：退化条件决定尺度可靠性

清晰小目标、混叠小目标和遮挡小目标需要不同的 P2–P5 权重；因子化退化后验可以比固定 P2、BiFPN 全局权重和普通注意力更准确地选择尺度。

### H3：退化状态可以校准定位

边界不确定性高的小目标不应被当作具有绝对精确边界的样本。退化条件的概率框或期望 IoU 可以降低像素量化和模糊边界导致的回归不稳定。

### H4：共享后验具有非冗余价值

同一个退化后验用于尺度路由和定位，应优于两个互不关联的注意力与损失模块。如果共享方式不优于独立方式，则“统一机制”假设被否证。

## 4. 研究范围

### 4.1 必须完成的主线

1. 重建 KITTI 标签和固定数据划分。
2. 实现 KITTI AP40、Easy、Moderate、Hard 评价。
3. 建立受控退化生成器和配对评价集。
4. 学习分辨率充分度、混叠噪声和可见性三个退化因素。
5. 使用退化后验控制 P2–P5 逐位置尺度路由。
6. 加入路由计算预算并进行等计算量对照。
7. 完成多随机种子、分组评价、校准和失败分析。

### 4.2 第二核心

1. 学习边界不确定性因素。
2. 实现退化条件的概率边界框或期望 IoU。
3. 与 CIoU、WIoU、Inner-IoU 进行对照。

### 4.3 条件扩展

以下内容只有在主线稳定后才进入：

1. 退化耦合正样本分配。
2. CityPersons 和 BDD100K 跨数据集验证。
3. 稀疏 P2 的真实推理加速。
4. 向第二种检测器或第二种 YOLO 规模迁移。

## 5. 数据与评价基础设施

### 5.1 当前问题

现有 `E:\myyolo\prepare_kitti.py` 将所有图像固定按 `1242×375` 归一化。本地 7481 张 KITTI 图像实际包含至少四种尺寸：

- 1242×375：6057 张；
- 1224×370：770 张；
- 1238×374：358 张；
- 1241×376：296 张。

现有标签因此存在系统性坐标误差。当前 6732/749 随机划分和普通 YOLO mAP 不能代替 KITTI 官方 AP40，现有 300 epoch 结果只能作为早期参考。

### 5.2 数据重建要求

1. 从每张 PNG 读取真实宽高后转换坐标。
2. 原始 KITTI 标签保持只读，不覆盖。
3. 训练标签与原始标签之间保留图像 ID 索引。
4. 保留类别、截断、遮挡、二维框和 DontCare。
5. 明确记录类别映射；不得静默把 Van、Truck、Tram、Misc 全部当成 Car。
6. 固定 train/val ID 文件和随机种子。
7. 转换后验证所有 YOLO 坐标位于合法范围。
8. 生成类别、框高、遮挡、截断和数据划分统计。

### 5.3 评价

主要评价包括：

- KITTI AP40；
- Car、Pedestrian、Cyclist；
- Easy、Moderate、Hard；
- mAP50、mAP50–95；
- 按原始框高和面积分箱的 AP/Recall；
- 按遮挡和截断分组；
- 退化强度—性能曲线；
- 退化因素预测的相关性、ECE、Brier Score 或 NLL；
- 参数量、FLOPs、显存、延迟和 P2 使用比例。

自定义小于 25 像素指标必须标明为扩展指标，不得称为 KITTI 官方指标。

## 6. 系统架构

数据流为：

1. 原始道路图像进入可控干预生成器。
2. 原图和干预视图通过共享 YOLOv8m Backbone。
3. Backbone 输出 P2、P3、P4、P5 特征。
4. 退化估计器输出因子化局部后验。
5. 后验指导 P2–P5 尺度可靠性路由。
6. 检测头输出类别、目标性和边界框。
7. 边界不确定性后验指导退化校准定位。

## 7. 单因素干预生成器

### 7.1 因素

定义：

\[
z=(z_s,z_a,z_v,z_b)
\]

其中：

- \(z_s\)：有效采样和分辨率充分度；
- \(z_a\)：混叠、模糊和无效高频；
- \(z_v\)：可见性和遮挡；
- \(z_b\)：边界定位不确定性。

### 7.2 干预

- \(z_s\)：缩放、重采样、亚像素平移；
- \(z_a\)：有/无反混叠下采样、模糊、噪声和压缩；
- \(z_v\)：限定区域和遮挡比例的结构化遮挡；
- \(z_b\)：与目标像素尺寸相关的边界扰动。

每个干预样本必须保存：

- 原图 ID；
- 干预因素；
- 干预强度；
- 随机参数；
- 变换后的边界框；
- 是否适合训练、校准或仅用于评价。

不得对原始数据集进行不可逆写入。

## 8. 因子化退化后验

模型估计：

\[
q_\theta(z\mid F)=
q(z_s\mid F)q(z_a\mid F)q(z_v\mid F)q(z_b\mid F)
\]

该分解表示输出可以分别评价，不要求四个真实因素统计独立。

对于只改变第 \(k\) 个因素的干预 \(T_k\)：

\[
L_{int} =
D(q(z_k\mid T_k(x)),\delta_k)
+\sum_{j\ne k}
D(q(z_j\mid T_k(x)),q(z_j\mid x))
\]

第一项监督被干预因素；第二项约束其他因素相对稳定。退化头需要提供：

- 每个因素的预测值或分布；
- 校准置信度；
- 可视化热图；
- 原图与干预视图的一致性诊断。

## 9. 退化可靠性尺度路由

逐位置尺度权重：

\[
\pi_l(x,y)=
\operatorname{Softmax}_l
g(F_l(x,y),z_s,z_a,z_v)
\]

融合：

\[
F^*(x,y)=
\sum_{l=2}^{5}\pi_l(x,y)\mathcal A_l(F_l,z_a)
\]

预期行为：

- 清晰极小目标提高 P2/P3 权重；
- 严重混叠时抑制不可靠的浅层高频；
- 遮挡严重时增加中高层语义上下文；
- 普通目标减少不必要的 P2 计算。

路由预算：

\[
L_{budget} =
\left|\mathbb E[C(\pi)]-B\right|
\]

第一版允许使用可微软路由。只有软路由机制成立后，才实现 top-k 或阈值稀疏执行。

## 10. 退化校准定位

边界不确定性表示为 \(z_b\)。根据它构造边界分布：

\[
\tilde b_{gt}\sim p(b\mid b_{gt},z_b)
\]

候选期望 IoU：

\[
L_{EIoU} =
1-\mathbb E_{\tilde b_{gt}}
[\operatorname{IoU}(\hat b,\tilde b_{gt})]
\]

实现约束：

1. 第一版保留 DFL 和 Task-Aligned Assigner。
2. \(z_b\) 需要独立监督和校准。
3. 进入回归权重或采样幅度的 \(z_b\) 默认停止梯度，避免模型通过放大不确定性逃避定位。
4. 边界扰动必须保持合法框。
5. 完全重合、无交集、极小框和退化框不得产生 NaN/Inf。
6. 如果期望 IoU 数值不稳定或不能优于简单标签平滑，则降级为实验分析，不强行作为最终贡献。

## 11. 总训练目标

\[
L =
L_{det}
+\lambda_1L_{int}
+\lambda_2L_{cal}
+\lambda_3L_{route}
+\lambda_4L_{budget}
+\lambda_5L_{EIoU}
\]

所有 \(\lambda\) 必须进入显式配置并保存到实验目录，不允许隐藏硬编码。

### 12.2 公平性

- 相同数据划分、输入尺寸、预训练来源和增强；
- 相同训练 epoch 和优化器预算；
- 参数量或 FLOPs 匹配；
- 主要结果至少三个随机种子；
- 报告均值、标准差和原始日志；
- 不以更高分辨率或更多训练解释核心提升；
- 服务器硬件、软件环境和吞吐设置完整记录。

## 13. 验证与测试

### 13.1 数据测试

- 多种图像尺寸坐标转换；
- 空标签和 DontCare；
- 越界框裁剪或拒绝；
- 图像、原始标签和转换标签一一对应；
- 固定划分可重复生成；
- 统计结果与原始数据一致。

### 13.2 干预测试

- 强度为零时近似恒等；
- 单因素干预只改变预期元数据；
- 框变换与图像变换一致；
- 随机种子可复现；
- 原始文件不被修改。

### 13.3 模型测试

- P2–P5 尺度和 stride 正确；
- 后验四个输出形状正确且有限；
- 路由权重非负、和为 1；
- 所有损失可反向传播；
- AMP 下无 NaN/Inf；
- 保存与恢复 checkpoint 后后验状态一致；
- 单 batch 和一轮冒烟训练通过。

### 13.4 评价测试

- AP40 阈值和难度筛选；
- DontCare 忽略；
- 类别 IoU 阈值；
- 无预测、无真值和完全匹配等边界情况；
- 与可信参考实现的小样本结果一致。

## 14. 实施边界

研究代码不得直接修改 Conda 环境中的 `site-packages`。优先使用项目内模块、子类、显式注册或可追踪补丁。若 Ultralytics 接口不足，需在实施计划中选择可复现的源码镜像或最小补丁方案。

所有实验必须由配置驱动。输出目录不得覆盖已有结果，并保存：

- 完整配置；
- Git 提交号；
- 环境版本；
- 数据划分摘要；
- 随机种子；
- 指标；
- 权重与日志路径。

## 15. 停止与收缩条件

出现以下任一情况时，不继续增加模块：

1. 退化因素不能区分已知干预；
2. 类别或位置捷径可以解释退化预测；
3. 等 FLOPs 后路由优势消失；
4. 共享后验不优于独立变量；
5. 提升只存在于单随机种子；
6. 小目标提升伴随不可接受的总体性能下降；
7. KITTI 提升不能在第二数据集保持趋势；
8. 边界不确定性不能校准。

若定位失败但路由成功，论文收缩为“干预监督退化后验与尺度路由”。若退化后验失败，停止 IFDR 主线，不用模块堆叠掩盖负结果。

## 16. 预期论文贡献

论文最终最多声明三个贡献：

1. 道路小目标的单因素退化干预与诊断协议；
2. 具有明确退化语义的因子化可靠性尺度路由；
3. 退化后验与定位学习的联合机制及非冗余验证。

P2、BiFPN、WIoU、动态路由、概率框本身都必须引用原始工作，不得单独声称原创。

## 17. 新颖性边界

可使用的有界表述：

> 截至检索日期，在已记录的公开论文、代码与功能同义检索范围内，尚未识别到使用单因素干预监督获得因子化道路退化后验，并让同一后验联合控制 RGB 小目标尺度路由和不确定性定位的方法。

不得使用“全球首次”“完全原创”“从未有人研究”等绝对表述。投稿前必须更新英文、中文、专利和预印本检索。

## 18. 交付阶段

1. 数据与评价可信化；
2. 退化诊断基线；
3. 因子化后验；
4. 尺度可靠性路由；
5. 退化校准定位；
6. 主要消融和多种子实验；
7. 跨数据集验证；
8. 论文图表与写作。

两周目标是完成前五阶段的核心代码和冒烟验证，不承诺两周内完成所有正式训练。正式实验由服务器并行执行。
